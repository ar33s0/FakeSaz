## 📝 Description | توضیحات

### **🇮🇷 فارسی**

فیک‌ساز یه ابزار تحت وب تک‌فایله (Single Page) هست که با کلیک یک دکمه اطلاعات هویتی فیک و واقع‌گرایانه برای ایرانی‌ها تولید می‌کنه.
شاید شما هم وبسایت‌هایی مثه https://www.fakenamegenerator.com/ رو دیده باشید که هویت فیک برای کشورهای مختلف می‌سازن.
من دنبال یه نمونه ایرانی‌ش گشتم ولی پیدا نکردم، برای همین تصمیم گرفتم خودم با کمک هوش مصنوعی یدونه بسازم.
با هر بار کلیک روی دکمه «تولید اطلاعات جدید»، شش دسته اطلاعات به صورت همزمان تولید می‌شه:

**🧑 اطلاعات فردی**
- نام و نام خانوادگی واقعی ایرانی (مثل علی کریمی، فاطمه محمدی)
- جنسیت (مرد/زن)
- تاریخ تولد شمسی (با رعایت تعداد روز هر ماه)
- شهر محل تولد به همراه استان
- کد ملی ۱۰ رقمی معتبر، بر اساس شهر و استان

**📞 اطلاعات تماس**
- شماره موبایل با پیش‌شماره‌های واقعی ایران (فرمت ۹۸+)
- آدرس کامل شامل استان، شهر، خیابان، کوچه و پلاک
- کد پستی ۱۰ رقمی معتبر بر اساس محدوده شهری
- نام کاربری ترکیبی انگلیسی برگرفته از نام فارسی

**🏦 اطلاعات بانکی**
- شماره کارت ۱۶ رقمی معتبر با الگوریتم لان (Luhn)
- تاریخ انقضای کارت (ماه/سال)
- CVV2 سه رقمی

**💼 سایر اطلاعات**
- شغل (از لیست مشاغل واقعی ایرانی)

همه چیز فقط توی مرورگر شما اجرا می‌شه و هیچ اطلاعاتی جایی ارسال نمی‌شه.

### **🇬🇧 English**

FakeSaz is a single-file web-based tool that generates realistic fake Iranian identities with a single click.
You've probably seen websites like https://www.fakenamegenerator.com/ that generate fake identities for various countries.
I looked for an Iranian version but couldn't find one, so I decided to build it myself with the help of AI.
Each click on "Generate New Data" simultaneously produces six categories of information:

**🧑 Personal Info**
- Realistic Iranian first and last name (e.g., Ali Karimi, Fatemeh Mohammadi)
- Gender (Male/Female)
- Persian (Shamsi) birth date with proper month-day logic
- City of birth along with province
- Valid 10-digit National ID (Melli Code), based on city and province

**📞 Contact Info**
- Mobile number with real Iranian prefixes (+98 format)
- Full address including province, city, street, alley, and plaque number
- 10-digit postal code based on city range
- English username derived from Persian name mapping

**🏦 Bank Info**
- Valid 16-digit card number via Luhn algorithm
- Card expiry date (month/year)
- 3-digit CVV2

**💼 Other Info**
- Job title (from a list of real Iranian occupations)

Everything runs entirely in your browser — no data is sent anywhere.
